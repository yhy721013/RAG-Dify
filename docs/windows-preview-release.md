供项目所有者授权的开发者在Windows本机测试、排错和继续开发。尚未指定开源许可证；本材料不是公开仓库上线或生产服务发布声明。


## 当前功能更新

新增[自动整理与集中复核](assisted-review.md)：可追溯元数据预填、层级/上下文建议、文档和条款疑点集中显示、普通条款批量对照批准、问题草稿逐题确认，以及相同文件复用和变化/依赖对照。旧分片遗漏的独立标题也会形成可应用的待复核结构建议；批准记录和已有人工修订不会自动被覆盖。

本轮采用规则，不新增LLM节点或依赖。真实批准范围仍为原有10条；合成资料用于新增界面审批验证，实际旧文件重复上传和规则回放单独记录。最新测试与剩余限制以[验收记录](acceptance.md)末尾为准。

## 交付与接手

从干净Git HEAD运行 `deploy/export-source.ps1`，ZIP名称包含源码提交。交付时附该ZIP的SHA-256与源码提交；ZIP不含 `.env`/`.env.portal`、PDF、解析包、数据库、照片、报告或虚拟环境。接收者解压后从[README](../README.md)开始，用自己的Dify/模型凭据和合法资料复现。

已有门户用户无需重新导入工作流；此前文档整理不改变产品运行行为；本轮新增辅助复核界面与接口，不改变Dify工作流和报告契约。维护旧单快照入口时，去绑定后的历史DSL需要自行绑定全部环境项并重新验证，不能当作原已绑定文件覆盖使用。

Git历史保留旧实例标识和历史验收事实。本轮仅整理当前交付文件，不重写历史；公开Git仓库前应完成历史审查、许可证和第三方资料授权决定。Quick Tunnel仍是临时入口，报告仍待专业复核，支持范围仍为普通卧式金属车床六项防护检查。
