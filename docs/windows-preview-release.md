供项目所有者授权的开发者在Windows本机测试、排错和继续开发。尚未指定开源许可证；本材料不是公开仓库上线或生产服务发布声明。

- 新增[历史版本与底层接口](legacy-stage-d.md)；旧单快照DSL清除实例绑定，保留节点、模型提示词和证据校验路径。

## 验证与边界

本轮在项目 `.venv` 重新执行全量pytest：166项通过，两条既有第三方弃用警告。另检查文档本地链接/锚点、PowerShell命令语法、门户手册唯一首次启动命令和两份交付DSL的占位绑定。

本轮未重新上传标准、索引或调用真实模型，也未修改已配置的Dify应用、密钥和业务数据库。历史MinerU与Dify实测及其限制见[验收记录](acceptance.md)，不能将历史验证声称为接收者环境已通过。

## 交付与接手

从干净Git HEAD运行 `deploy/export-source.ps1`，ZIP名称包含源码提交。交付时附该ZIP的SHA-256与源码提交；ZIP不含 `.env`/`.env.portal`、PDF、解析包、数据库、照片、报告或虚拟环境。接收者解压后从[README](../README.md)开始，用自己的Dify/模型凭据和合法资料复现。

已有门户用户无需重新导入工作流；本轮不改变产品运行行为。维护旧单快照入口时，去绑定后的历史DSL需要自行绑定全部环境项并重新验证，不能当作原已绑定文件覆盖使用。

Git历史保留旧实例标识和历史验收事实。本轮仅整理当前交付文件，不重写历史；公开Git仓库前应完成历史审查、许可证和第三方资料授权决定。Quick Tunnel仍是临时入口，报告仍待专业复核，支持范围仍为普通卧式金属车床六项防护检查。
